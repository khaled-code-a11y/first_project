# 🎓 University Website

A modern and responsive **University Website** developed to simulate the official website of an educational institution. The project focuses on providing students and visitors with an intuitive experience through a clean interface and well-organized content.

## 📖 Overview

The website includes multiple pages that represent the core sections of a university portal, such as home, about, courses, blogs, student life, registration, and contact pages.

It was built using only front-end technologies with a strong emphasis on responsive design and user-friendly navigation.

## ✨ Features

* 🏛️ Modern University Landing Page
* 📚 Courses & Academic Programs
* 👨‍🎓 Student Life Section
* 📰 Blog & News Pages
* 📝 Student Registration Page
* 🔐 Login Interface
* 📞 Contact Page
* 📱 Fully Responsive Design
* ⚡ Clean and Lightweight Code

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
